แบบฝึกปฏิบัติ: HTML Link และ Image

เรียนรู้การสร้างลิงก์และการแทรกรูปภาพด้วยแท็ก HTML
พร้อมตัวอย่างและการตกแต่งด้วย CSS

🔗ตัวอย่างลิงค์(Link Examples)

ผลลัพธ์
ไปยังเว็บไซต์มหาวิทยาลัย เปิด google ในแท็บใหม่
✉️ส่งอีเมลถึงผู้สอน
←กลับไปหน้าแรก
โค้ด HTML
  1. <a href = "https://www.npru.ac.th" > เว็บไซต์มหาวิทยาลัย </a>
  2. <a href = "https://www.google.com" target = "_blank" > เปิด Google ในแท็บใหม่ </a>
  3. <a href="mailto:teacher@example.com">ส่งอีเมล</a>
  4. <a href="index.html">กลับหน้าแรก</a>

🔗ตัวอย่างรูปภาพ(Image Examples)

ผลลัพธ์
โค้ด HTML
  1. <img src = "https://campus.jpg" alt = "ภาพมหาวิทยาลัย" width = "100" >
  2. <img src = "https://student.jpg" alt = "นักศึกษาSE" width = "180" >
  3. <img src = "https://logo.png" alt = "โลโก้สาขาSE" width = "80" >

🚩 จุดประสงค์การเรียนรู้

1 อธิบายวิธีการใช้แท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่างๆ
2 แทรกรูปภาพด้วยแท็ก <img> พร้อมกำหนดคุณสมบัติพื้นฐาน
3 ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน

🏷️แท็กที่ใช้บ่อย

<a> href target <img> src alt width height

🚩 กิจกรรมฝึกปฏิบัติ

  1. 1 สร้างลิงค์อย่างน้อย 3 แบบ
  2. 2 แทรกรูปภาพอย่างน้อย 2 รูป
  3. 3 ใส่ alt ให้กับรูปภาพทุกภาพ
  4. 4 ใส่ css เปลี่ยนสีลิงค์เมื่อ hover
  5. 5 ตกแต่งรูปภาพด้วย border-radius หรือ box-shadow
  6. 6 บันทึกไฟล์ชื่อ "link-image.html"

เกรดความรู้

แท็ก <a> ใช้สำหรับสร้างลิงก์ (Hyperlink) เพื่อเชื่อมโยงไปยังหน้าเว็บ ไฟล์ หรือที่อยู่อีเมลต่างๆ โดยใช้แอตทริบิวต์ href ระบุปลายทางของลิงก์ แท็ก <img> ใช้สำหรับแทรกรูปภาพ โดยใช้แอตทริบิวต์ src ระบุที่อยู่ของไฟล์รูปภาพ และ alt ระบุข้อความอธิบายรูปภาพ ซึ่งสำคัญต่อการเข้าถึงได้ (Accessibility) และช่วยแสดงข้อความเมื่อไม่สามารถโหลดรูปได้ .CSS สามารถใช้ตกแต่งลิงก์ด้วย link color,เอฟเฟกต์เมื่อ hover,ขนาดของรูปภาพ,ขอบ (border),มุมโค้ง(border-radius)และเงา(box-shadow)เพื่อให้หน้าเว็บสวยงามและน่าใช้งานมากยิ่งขึ้น
